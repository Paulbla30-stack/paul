Specify

The Character Specification and Character Vitals

Puts the deployed system's character under governance: the five surfaces a deploying organisation actually controls.

What it does

Organisations govern budgets, data and uptime and leave ungoverned the variable that decides adoption: how the system behaves with people. Machine dispositions are made, not found. The specification names the five character surfaces a deploying organisation controls and sets vitals for each, so that temperament becomes a written, monitored property rather than an accident of vendor defaults.

When it is used

Third. Before go-live, and re-issued whenever the underlying model or its configuration changes.
