Stage 5 of 8 · Trial

Trial

The Floor Test capture sheets

Ninety days, no budget, no new software: baseline nine vitals, change one thing, read the result — and send it back, especially if it is null.

What it does

A field protocol for testing the framework's own claims on a real unit. Nine team vitals are baselined, one thing is changed, and the result is read at ninety days. The estate's standing request to every reader is to run it and return the result, including a null one.

When it is used

Fifth. After go-live, for the first ninety days, and repeatable for each subsequent change.
